# WorkMind V5 — OpenRouter
Render: Build `npm install`; Start `npm start`; Health `/api/health`.
Environment: `OPENROUTER_API_KEY` required. Optional `WORKMIND_MODEL` (default `openai/gpt-oss-20b`) and `WORKMIND_TRANSCRIBE_MODEL` (default `openai/whisper-large-v3`).
Keep the API key out of GitHub. iPhone browser microphone capture may stop when locked/backgrounded. Follow applicable workplace recording/consent rules.
